Fast Refresh — edits appear automatically

All three devices run the live dev app (port 8081, or ?app=PORT). Fast Refresh updates them a few seconds after any code change, keeping your state. Each frame reserves the status bar and gesture area the way the Android shell does (safe areas), so layouts match the APK. Auto sign-in logs the iPhone (and small Android) in as Person A — preview.a@networq.co.in and the Pixel as Person B — preview.b@networq.co.in (password Preview#2026). They run on different hosts (localhost vs 127.0.0.1) so both stay signed in at once — perfect for Radar and connection requests. Untick it to test the sign-in screens. Use Screen to open a path such as /?join=NQ-ABC123. Mode switches between the Android app layout and the mobile website. The dev app uses your real Supabase project.
